      \item \textbf{Microsoft SQL Server connector} (\texttt{pw.io.mssql}): pure-Rust TDS implementation via \texttt{tiberius} (no ODBC drivers); static-polling and Change Data Capture (CDC) streaming reads, snapshot / change-stream writes, and full SQL Server type mapping (\resumeLink{https://github.com/pathwaycom/pathway/pull/205}{PR \#205}).
      \item \textbf{RabbitMQ Streams connector} (\texttt{pw.io.rabbitmq}): native read/write on \texttt{rabbitmq-stream-client} with TLS, AMQP 1.0 message keys, and parallel readers; shipped an end-to-end RabbitMQ $\rightarrow$ Pathway $\rightarrow$ PostgreSQL ETL example (\resumeLink{https://github.com/pathwaycom/pathway/pull/207}{PR \#207}).
